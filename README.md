# Фигуры в дополненной реальности

Учебный проект: выбор куба или шара, просмотр 3D-модели на странице и размещение на столе или полу с iPhone без маркеров.

## Важно об ограничениях

В режиме AR открывается системный экран Apple AR Quick Look. Свои HTML-кнопки поверх камеры и счётчик найденных плоскостей добавить нельзя: экраном управляет iOS. Поиск поверхности выполняет ARKit, а не написанный нами алгоритм. Это удобно честно объяснить преподавателю. Вид и точная последовательность действий зависят от версии iOS. Для проверки используйте реальный iPhone; гарантировать работу на каждом устройстве и в любой обстановке нельзя.

## Технологии

- HTML и CSS — содержимое и оформление страницы.
- JavaScript — переключение моделей.
- Google model-viewer — 3D-просмотр GLB, управление пальцем и запуск AR.
- AR Quick Look — системный просмотр USDZ в AR на iPhone.
- ARKit — технологии Apple, с помощью которых телефон оценивает движение и окружающую сцену и находит подходящую поверхность.

Телефон анализирует изображение с камеры и данные датчиков, определяет характерные точки и оценивает положение горизонтальных поверхностей. Quick Look размещает виртуальный объект относительно найденной поверхности. Печатный маркер или QR-код для этого не нужны. Отражающие, однотонные и плохо освещённые поверхности распознать сложнее.

## Файлы

```text
AR-university/
├── index.html
├── style.css
├── script.js
├── README.md
├── ИНСТРУКЦИЯ.md
└── models/
    ├── cube.glb
    └── sphere.glb
```

Модели уже входят в проект. Размер ребра куба и диаметр шара — примерно 0,2 м. USDZ заранее не нужен: model-viewer создаёт его из GLB при запуске Quick Look. Интернет нужен для загрузки библиотеки через CDN и сайта через GitHub Pages.

## Требования

Совместимый с ARKit iPhone и Safari. Сам Apple Quick Look доступен начиная с iOS 12, однако это не гарантия работы используемой версии model-viewer на всех старых версиях iOS; лучше обновить iOS до последней доступной. Для создания и публикации сайта достаточно Windows и бесплатной учётной записи GitHub; Mac и платная программа разработчика Apple не нужны.

## Запуск и использование

Подробная инструкция — в файле ИНСТРУКЦИЯ.md. Для локального предварительного просмотра откройте папку в VS Code и запустите index.html через расширение Live Server. Для iPhone опубликуйте проект на GitHub Pages, откройте HTTPS-ссылку именно в Safari, выберите фигуру, нажмите «Посмотреть в AR» и следуйте подсказкам iPhone. Поворачивайте, перемещайте и масштабируйте объект жестами Quick Look. На компьютере проверяется только превью, не iPhone AR.

## Проблемы и решения

- Нет кнопки AR: откройте сайт в Safari на поддерживаемом iPhone, дождитесь загрузки модели; на ПК её отсутствие ожидаемо.
- AR не открывается: проверьте соединение, используйте HTTPS и обновите iOS; убедитесь, что запуск происходит по нажатию кнопки. Попробуйте перезапустить Safari.
- Камера чёрная: закройте другие приложения с камерой, проверьте ограничения и разрешения камеры в настройках iPhone, перезапустите телефон.
- Модель не загружается: проверьте имена и регистр букв, папку models, наличие обоих GLB и интернета для CDN; откройте адрес файла модели через сайт.
- Неверный формат: для src нужен GLB; Quick Look использует USDZ, который этот проект создаёт автоматически. Нельзя просто переименовать GLB в USDZ.
- Сайт не по HTTPS: используйте адрес https://...github.io/...; адрес localhost с ПК на телефоне не работает.
- Ссылку открыли внутри мессенджера: скопируйте её и вставьте в адресную строку Safari.
- После обновления GitHub Pages видна старая версия: подождите завершения публикации в Settings → Pages или Actions, обновите страницу, при необходимости откройте её в частной вкладке Safari.
- Плоскость долго не находится: включите свет, направьте телефон на поверхность с видимыми деталями, медленно двигайте им; избегайте зеркальных и полностью однотонных поверхностей.

## Возможные улучшения

Добавить галерею фигур, текстовые карточки с фактами о них, смену цветов на странице, обучающие подсказки, звуковое описание и отдельный режим сравнения размеров. Для управления интерфейсом поверх камеры понадобится другой технический подход, а не только HTML поверх Quick Look.
