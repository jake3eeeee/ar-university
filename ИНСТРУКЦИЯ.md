# Подробная инструкция

Всё необходимое для сайта и две модели уже лежат в папке. Для первого запуска Blender и Git устанавливать не обязательно. USDZ создаётся автоматически в момент нажатия AR; отдельного файла .usdz в папке нет. Если преподаватель требует именно отдельные файлы USDZ, см. шаг 10. Используйте настоящий iPhone для проверки AR: на Windows проверяется только страница и 3D-превью.

## Шаг 1. Распакуйте архив

Нажмите правой кнопкой по ZIP → «Извлечь все» → «Извлечь». Откройте папку AR-university. В ней лежат index.html, style.css, script.js, README.md и папка models. Не меняйте имена файлов. В Windows включите в проводнике «Вид» → «Показать» → «Расширения имён файлов», чтобы не получить index.html.txt.

## Шаг 2. Установите программы

1. Установите бесплатный Visual Studio Code: https://code.visualstudio.com/ → Download for Windows → запустите установщик.
2. Для собственной работы с моделями установите Blender: https://www.blender.org/download/ → Download Blender → запустите установщик.
3. Git необязателен: ниже мы загрузим сайт через браузер. Если нужен Git, скачайте https://git-scm.com/download/win и установите с настройками по умолчанию. Команды Git в этой инструкции не нужны.

## Шаг 3. Проверьте страницу на компьютере

1. Откройте VS Code → File → Open Folder → выберите AR-university → Select Folder. Если появится вопрос о доверии к папке, подтвердите для этой папки.
2. Нажмите значок Extensions слева (четыре квадрата), найдите Live Server от Ritwick Dey и нажмите Install.
3. В списке файлов справа нажмите правой кнопкой index.html → Open with Live Server. В браузере откроется адрес вида http://127.0.0.1:5500/.
4. Должен появиться синий куб; кнопка «Шар» меняет его на оранжевый шар. Потяните модель мышкой. Подключение к интернету нужно для загрузки model-viewer. AR-кнопка на Windows может отсутствовать — это нормально.

## Шаг 4. Создайте бесплатный аккаунт GitHub

Откройте https://github.com/ → Sign up и следуйте инструкциям, включая подтверждение электронной почты. Если аккаунт уже есть, нажмите Sign in. Ник и название репозитория будут видны в адресе сайта.

## Шаг 5. Создайте репозиторий

1. В GitHub нажмите значок «+» сверху → New repository.
2. В Repository name введите, например, ar-university.
3. Выберите Public. Для бесплатного GitHub Pages используйте публичный репозиторий; его содержимое увидят другие люди, поэтому не загружайте личные данные.
4. Нажмите Create repository. Если GitHub предлагает добавить README, можно оставить поле пустым: готовый README уже есть в проекте.

## Шаг 6. Загрузите файлы

1. В новом репозитории нажмите ссылку «uploading an existing file» либо Add file → Upload files.
2. В проводнике откройте AR-university, выделите все файлы и папку models внутри неё и перетащите в окно загрузки GitHub. Загружайте содержимое папки, а не саму папку AR-university целиком: index.html должен оказаться в корне репозитория.
3. Убедитесь, что в списке присутствуют models/cube.glb и models/sphere.glb, а index.html находится без префикса папки. Нажмите Commit changes.
4. Если папка не перенеслась, создайте файлы в папке через интерфейс или повторите перетаскивание в поддерживаемом браузере с сохранением путей. Проверьте отображение папки models в репозитории.

## Шаг 7. Включите GitHub Pages

1. В репозитории нажмите Settings → Pages в меню слева.
2. В Build and deployment → Source выберите Deploy from a branch.
3. В Branch выберите main и / (root), нажмите Save.
4. Подождите несколько минут и обновите Settings → Pages. Появится Visit site и ссылка вида https://ИМЯ.github.io/ar-university/ . Пользуйтесь ссылкой из GitHub, а не примером. Если ссылка долго не появляется, посмотрите вкладку Actions на наличие ошибки сборки.

## Шаг 8. Запустите AR на iPhone

1. Передайте HTTPS-ссылку на телефон, скопируйте её и вставьте в адресную строку Safari. Встроенный браузер мессенджера может работать иначе.
2. Дождитесь появления модели, выберите «Куб» или «Шар», нажмите «Посмотреть в AR». При первом запуске может потребоваться время на подготовку USDZ.
3. Если появился выбор «Объект / AR», выберите AR. Следуйте системным подсказкам; направьте камеру на освещённый стол или пол, медленно перемещайте телефон. При появлении запроса разрешите доступ к камере.
4. Двигайте фигуру одним пальцем, вращайте и изменяйте размер жестами двумя пальцами. Конкретные подсказки зависят от iOS. Чтобы вернуться на страницу, закройте системный просмотр.

## Шаг 9. QR-код только для открытия ссылки

QR-код для AR не требуется. Чтобы преподавателю было удобно открыть сайт, после публикации откройте готовую HTTPS-ссылку в Google Chrome на компьютере → нажмите кнопку «Поделиться» справа в адресной строке → «Создать QR-код» → «Скачать». В некоторых версиях Chrome пункт может называться иначе или находиться в меню правой кнопки страницы. Проверьте его камерой iPhone и откройте ссылку в Safari. Сам код не участвует в поиске плоскости и не служит AR-маркером.

## Шаг 10. Как самостоятельно сделать куб и шар в Blender

Готовые GLB уже входят в архив; этот шаг нужен для изучения или замены моделей. Названия меню могут немного отличаться в зависимости от версии Blender. Создавайте каждую модель отдельно.

1. Откройте Blender → General. Выделите все объекты клавишей A, удалите клавишей X → Delete.
2. Куб: Shift+A → Mesh → Cube. По умолчанию он имеет сторону 2 м; нажмите S, введите 0.1, затем Enter. Это даст сторону 0,2 м. Затем Ctrl+A → Scale.
3. В правой панели Material Properties (значок сферы) нажмите New. В разделе Surface → Base Color выберите цвет. Используйте простой материал Principled BSDF без сложных узлов: так экспорт надёжнее. Для просмотра цвета нажмите Material Preview (иконка сферы вверху окна 3D).
4. Выделите куб. File → Export → glTF 2.0 → формат glTF Binary (.glb). Включите Selected Objects, выберите папку models, имя cube.glb и нажмите Export glTF 2.0. При замене готового файла подтвердите перезапись.
5. Шар: удалите куб (выделите → X → Delete), Shift+A → Mesh → UV Sphere. Стандартный радиус 1 м: S → 0.1 → Enter, затем Ctrl+A → Scale. Правая кнопка → Shade Smooth. Создайте цветной материал так же, как для куба. Выделите шар и экспортируйте в models/sphere.glb с настройкой Selected Objects.
6. Для отдельного USDZ: выделите нужную модель → File → Export → Universal Scene Description (.usd*) → укажите имя cube.usdz или sphere.usdz в поле имени. Включите экспорт только выделенного объекта (Selection Only / Selected Objects, если доступно), экспорт материалов и текстур; нажмите Export USD. Новые версии Blender поддерживают USDZ, но интерфейс зависит от версии. Сложные материалы могут выглядеть иначе: обязательно проверьте результат на iPhone. Не переименовывайте GLB в USDZ — это разные форматы.
7. В этом проекте дополнительные USDZ не подключены: автоматическая конвертация из GLB проще. Если отдельные USDZ нужны для отчёта, положите их в models и проверяйте их совместимость на реальном iPhone. Альтернатива ручному экспорту — встроенная конвертация model-viewer при запуске AR, без Mac и платного сервиса.

## Что означают атрибуты

В index.html: src указывает GLB; ar разрешает запуск AR; ar-modes="quick-look" выбирает системный режим iPhone; ar-placement="floor" обозначает горизонтальное размещение, но детали его применения определяет Quick Look; camera-controls разрешает вращение и масштабирование превью. В некоторых примерах встречается placement="floor", но правильное имя в model-viewer — ar-placement. Атрибут ios-src в проекте специально не указан: он задаёт путь к готовому USDZ и отключает необходимость создавать его автоматически. Если задать ios-src, при переключении фигур обязательно переключайте и его; иначе в AR может открываться прежняя модель.

## Объяснение преподавателю

«Это веб-приложение: страницу и выбор моделей я реализовал на HTML, CSS и JavaScript. model-viewer показывает GLB и передаёт модель в Apple AR Quick Look. Для распознавания поверхности и размещения модели используется ARKit в iPhone. Печатные маркеры не нужны. Системный экран камеры управляется iOS, поэтому собственный счётчик плоскостей или произвольные HTML-кнопки поверх него недоступны».

Возможные неполадки и способы решения перечислены в README.md.
